# WebAPINET6

A sample **ASP.NET Core .NET 6 Web API** project demonstrating API architecture and best practices (Repository pattern, layered structure) using C#.  
This project is intended to show how to build a clean and maintainable Web API backend with .NET 6.

## 🚀 Features

- Built with **.NET 6** and **ASP.NET Core Web API**
- Well-structured **layered architecture**
  - Controllers
  - Services
  - Repository
  - Entities/Models
  - Contracts/Interfaces
- Includes validation filters and custom middleware
- Useful starter template for enterprise APIs
